FIGURINHAS COPA 2026 — Control de cromos

Toca un cromo para cambiar su estado. Los datos se guardan automáticamente en este dispositivo.
Cómo usarlo: cada clic cambia Falta → Tengo → Repetido → Sin marcar. Cuando un cromo está como Repetido, usa los botones − / + para indicar cuántos tienes repetidos.
ROJO = FALTA VERDE = TENGO NARANJA = REPETIDO ROJO = TE FALTA
🔄 Intercambio de cromos
Aquí aparecen automáticamente tus repetidos para ofrecer y los cromos que te faltan para buscar.

🟠 Mis repetidos — para cambiar

🔴 Me faltan — para buscar
